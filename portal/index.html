Works offline

Every tool is a static web page with all code bundled locally. Copy this site to a computer without Internet access and serve it with any web server.

Private by design

Your files and data are processed in your browser. Nothing is uploaded, and there is no analytics or telemetry. A Content-Security-Policy blocks loading anything from other hosts.

Run it yourself

Serve the built folder with e.g. python3 -m http.server 8080 and open http://localhost:8080/. See OFFLINE-README.txt.
